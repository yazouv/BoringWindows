# Sécurité / Security

**Français** — Pour signaler une faille, n'ouvre pas d'issue publique : utilise
**Security › Report a vulnerability** sur le dépôt GitHub (signalement privé).
Points sensibles : le relais des hooks Claude Code (il peut répondre aux
demandes de permission), la mise à jour automatique, les secrets d'agenda
(gestionnaire d'identifiants) et les plugins WASM.

**English** — To report a vulnerability, please don't open a public issue: use
**Security › Report a vulnerability** on the GitHub repository (private
report). Sensitive areas: the Claude Code hook relay (it can answer permission
requests), automatic updates, calendar secrets (credential manager) and WASM
plugins.
